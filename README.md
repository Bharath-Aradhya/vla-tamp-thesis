# VLA-executed, PDDL-planned manipulation loop (Unitree G1, MuJoCo)

Master's thesis project. A symbolic planner (Fast Downward, hand-written PDDL domain) chooses
subtasks; each subtask is executed by a fine-tuned VLA on one arm and hand of a simulated
Unitree G1; a completion check after every subtask triggers replanning on failure.

## Layout

| Path | What it is |
|---|---|
| `scripts/inspect_g1.py` | Loads the Menagerie G1 (with hands), prints joints/actuators, tests standing and rendering |
| `scripts/build_and_check.py` | Builds `models/` (fixed base, head camera, table, cube) and checks the scene |
| `scripts/reach_test.py` | One reach-and-grasp attempt with pictures and diagnostics |
| `scripts/grasp_sweep.py` | Searches the thumb pose and palm offset (81 variants) |
| `scripts/grasp_robustness.py` | Repeats a grasp on 30 random cube poses |
| `scripts/grasp_refine.py` | Searches the grasp point by success rate, then validates on 30 new poses |
| `scripts/symbolic.py` | Minimal PDDL reader and state simulator (plan checking, state tracking) |
| `scripts/plan.py` | Runs Fast Downward on the domain and checks every plan |
| `scripts/test_symbolic.py` | Tests the domain with the state simulator (valid and invalid plans) |
| `pddl/domain.pddl`, `pddl/problems/` | The fixed domain (5 actions) and 7 task instances |
| `results/` | CSV results from the Month 1 grasp experiments |
| `docs/` | The thesis proposal as PDF |

## Setup (Windows, Command Prompt)

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
git clone --depth 1 https://github.com/google-deepmind/mujoco_menagerie.git
python scripts\build_and_check.py
```

Run scripts from the project root. `models/` is generated by `build_and_check.py` and is not
committed (it contains a machine-specific path).

## Fast Downward

Easiest on Windows (prebuilt wheel, no compiler):

```
pip install unified-planning up-fast-downward
python scripts\plan.py --all
```

Alternative: build Fast Downward from source (Linux or WSL; on Windows it needs Visual Studio),
then set `FAST_DOWNWARD` to the folder that contains `fast-downward.py`.
`scripts/plan.py` uses the source build if it finds one, otherwise the pip package.

## Month 1 status

- Platform: Unitree G1 with hands (H1 has no hands). Fixed base, head camera, table and cube added.
- Scripted grasp: grasp point 0.14 m along the fingers, 0.02 m across the palm, 0.02 m above
  the cube centre; thumb joints (0.0, 0.7, -1.6); index/middle closed at 1.2 / 1.4.
  Validated on 30 fresh random cube poses: 22/30 (73%) held; 20/23 (87%) for cubes at x < 0.375.
  Failures are complete misses (cube never lifted); holds are stable (slip <= 0.2 cm).
- Planner: PDDL domain with 5 actions (pick, place, stack, unstack, push) and 7 tasks; every plan is
  checked by an independent simulator (`scripts/symbolic.py`).
- Open: GPU access; action space of the VLA (joint targets vs end-effector deltas).
